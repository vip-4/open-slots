What is Open Slots?

Open Slots is a free, open-source HTML5 slot machine that runs entirely in your browser. It is a lightweight demonstration of a five-reel casino game built with plain HTML, CSS and vanilla JavaScript — no frameworks, no Flash, no build step at runtime and no external network requests. Reel motion is powered by the browser's native WAAPI.

This deployment is based on the popular upstream project johakr/html5-slot-machine (MIT License), adapted for static hosting with a zero-dependency ES-module build and an added search- and AI-friendly content layer.

  • Five reels, three visible symbols per reel, nine distinct icons.
  • One-tap SPIN plus an Autoplay toggle for continuous play.
  • Fully responsive layout for desktop, tablet and mobile browsers.
  • Small footprint: a handful of static files, no tracking, no analytics, no cookies.
  • Keyboard accessible controls and a visible focus state.

How to play

  1. Open the page in any modern browser — nothing to install or sign up for.
  2. Press SPIN (or focus it and press Enter / Space) to start the five reels.
  3. The reels use staggered animation durations, so they settle one after another.
  4. Optionally tick Autoplay to keep spinning automatically.
  5. Read the on-screen jackpot counter as decoration — it is not a balance.

This is a visual proof of concept. The upstream demo selects symbols uniformly at random and does not compute wins, paylines, RTP or payouts.

Fairness & play-money policy

Open Slots is entertainment software, not a gambling operator. It uses play money only. There is no real-money wagering, no deposit, no withdrawal, no prize, no cash-out and no reward conversion. The jackpot display is a decorative counter inherited from the upstream demo. The game does not require an account, does not collect personal data, does not set cookies and makes no third-party requests.

Because the upstream project is a visual proof of concept, symbol selection is uniform random and no paytable, payline evaluation or return-to-player (RTP) calculation is implemented. Nothing on this page should be read as an offer of gambling. Intended for adults 18 and over.

Frequently asked questions

Is Open Slots free to play?
Yes. It is a free, open-source browser demo with no accounts, payments, downloads or real-money wagering.
Does this game pay real money?
No. It is a play-money demonstration with no cash-out, deposits, prizes or payout table. The jackpot counter is decorative.
What technology powers the reels?
Plain HTML, CSS and vanilla JavaScript. Reel motion uses the native Web Animations API — no frameworks, no Flash, no external runtime dependencies.
How many reels and symbols are there?
Five reels showing three symbols each, drawn from nine space-themed icons: AT-AT, C-3PO, Darth Vader, Death Star, Millennium Falcon, R2-D2, Stormtrooper, TIE Fighter and Yoda.
Is the game open source?
Yes. The upstream project is johakr/html5-slot-machine on GitHub under the MIT License. Icons are by KPD Media and are free for private and commercial use without attribution.
Does it work on mobile?
Yes. The layout is responsive and works in modern mobile browsers. Tap SPIN to play, or enable Autoplay for continuous spins.
